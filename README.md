O **VivaPay** é um projeto inovador desenvolvido para automatizar sistemas de pagamento e oferecer soluções personalizadas que impulsionam a eficiência empresarial.  

---

## ℹ️ Sobre o Projeto  

O **VivaPay** tem como objetivo facilitar a gestão de eventos com tecnologias de ponta. Ele combina robustez e inovação para otimizar operações de pagamento.  

### Principais Tecnologias Utilizadas:  
- **Linguagens**: Java, TypeScript  
- **Frameworks**: JavaFX, Vue, Ionic  
- **Banco de Dados**: PostgreSQL  

---

## 🛠️ Ferramentas de Desenvolvimento  

Durante o desenvolvimento do projeto, utilizamos as seguintes ferramentas:  
- **IntelliJ IDEA**: Para desenvolvimento em Java  
- **Visual Studio Code**: Para edição de código em TypeScript e Vue  
- **Scene Builder**: Para criação de interfaces em JavaFX
